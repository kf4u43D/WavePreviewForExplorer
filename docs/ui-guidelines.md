# Guide UI

## 1. Direction visuelle

Interface professionnelle, sobre, précise.

À éviter :

- look lecteur média grand public ;
- gros dégradés ;
- animations inutiles ;
- couleurs trop vives ;
- surcharge d’informations.

## 2. Preview Handler

Disposition :

```text
[Nom du fichier]
[Format · Durée · Sample rate]

[Waveform principale]
[Timeline]

[Play/Pause] [00:03.120 / 00:12.480]
[Mono/Stereo · 24-bit · 48 kHz · 12.4 MB]
```

## 3. Miniatures

- fond neutre ;
- waveform contrastée ;
- durée optionnelle en bas à droite ;
- stéréo visible en deux bandes si taille suffisante ;
- éviter tout texte si la miniature est trop petite.

## 4. Accessibilité

- contraste suffisant ;
- compatible thème clair/sombre ;
- taille texte lisible ;
- navigation clavier ;
- indication claire de lecture en cours.
